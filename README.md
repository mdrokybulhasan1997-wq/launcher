# Dock Launcher — কিভাবে APK পাবেন (Android Studio ছাড়াই)

## ধাপ ১: GitHub অ্যাকাউন্ট বানান
- https://github.com এ গিয়ে ফ্রি অ্যাকাউন্ট খুলুন (না থাকলে)

## ধাপ ২: নতুন Repository বানান
- GitHub-এ লগইন করে উপরে ডানদিকে **+** বাটনে ক্লিক করে **New repository**
- নাম দিন: `CustomDockLauncher`
- **Public** সিলেক্ট করুন, তারপর **Create repository**

## ধাপ ৩: এই ফোল্ডারের সব ফাইল আপলোড করুন
- নতুন খোলা রিপোর পেজে **"uploading an existing file"** লিংকে ক্লিক করুন
- এই zip ফাইলটা এক্সট্র্যাক্ট করে ভেতরের সব ফাইল ও ফোল্ডার (app, .github, settings.gradle, build.gradle) ড্র্যাগ করে ওয়েবপেজে ছেড়ে দিন
- নিচে **Commit changes** বাটনে ক্লিক করুন

⚠️ জরুরি: `.github` ফোল্ডারটা hidden (লুকানো) ফোল্ডার, তাই আপলোড করার সময় খেয়াল রাখবেন এটাও যেন যায়। এক্সট্র্যাক্ট করা ফোল্ডার থেকে পুরো জিনিসটা zip আকারে আপলোড করাই সবচেয়ে নিরাপদ (GitHub zip আপলোড সাপোর্ট করে যদি drag-drop করেন)।

## ধাপ ৪: বিল্ড হওয়া পর্যন্ত অপেক্ষা করুন
- রিপোর উপরে **Actions** ট্যাবে ক্লিক করুন
- একটা workflow run দেখতে পাবেন (নাম "Build APK"), সেটায় ক্লিক করুন
- ২-৪ মিনিট অপেক্ষা করুন — সবুজ টিক ✅ আসলে বিল্ড সফল

## ধাপ ৫: APK ডাউনলোড করুন
- একই পেজে নিচে **Artifacts** সেকশনে `dock-launcher-apk` নামে একটা জিপ ফাইল পাবেন
- সেটা ডাউনলোড করে আনজিপ করলে `app-debug.apk` পাবেন

## ধাপ ৬: ফোনে ইনস্টল করুন
- APK ফাইলটা ফোনে পাঠান (Google Drive / USB / যেকোনোভাবে)
- ফোনে ফাইলে ট্যাপ করুন → "Install unknown apps" পারমিশন চাইলে Allow করুন → Install
- ইনস্টলের পর **Settings > Apps > Default apps > Home app** এ গিয়ে **Dock Launcher** সিলেক্ট করুন

## অ্যাপ যেভাবে কাজ করে
- খালি স্লটে ট্যাপ করলে অ্যাপ লিস্ট থেকে বেছে নিতে পারবেন
- ভরা স্লটে ট্যাপ করলে অ্যাপ ওপেন হবে
- ভরা স্লটে **দীর্ঘক্ষণ চাপ দিলে (long-press)** Replace বা Remove অপশন আসবে
- অ্যাপ খোলার সাথে সাথে স্ট্যাটাস বার/নোটিফিকেশন বার ও নেভিগেশন বার স্বয়ংক্রিয়ভাবে হাইড হয়ে যাবে (উপর/নিচ থেকে সোয়াইপ করলে সাময়িকভাবে দেখা যাবে)
